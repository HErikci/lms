Ders 4: State ve Props Yönetimi

Bu Derste Neler Öğreneceksiniz?

React uygulamalarında veri akışının temel yapı taşı olan state ve props mekanizmalarını derinlemesine inceliyoruz. Tek yönlü veri akışı (unidirectional data flow), state kaldırma (lifting state up) ve prop drilling problemlerinin modern fonksiyonel bileşenlerde nasıl çözümleneceğini uygulamalı senaryolar üzerinden takip edeceğiz.

useState ile Yeniden Render

Bileşen yaşam döngüsü ve asenkron state güncellemelerinde stale state hatalarından kaçınma.

code UserCounter.jsx Panoya Kopyala 
function UserCounter({ initialCount = 0, onThresholdReached }) {
  const [count, setCount] = useState(initialCount);

  const increment = () => {
    setCount(prev => prev + 1);
  };
  return <button onClick={increment}>Değer: {count}</button>;
}
