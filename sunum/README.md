# Claude Code Agent Teams sunumu

`agent-teams-lms.html` dosyasını bir tarayıcıda açın. Sunum internetsiz çalışır; ok tuşlarıyla gezinir, `F` ile tam ekrana geçer, `P` ile yazdırma/PDF penceresini açarsınız. Yazdırırken yatay sayfa ve arka plan grafiklerini etkinleştirin.

17 slayt, Claude Code Agent Teams yapısını bu depodaki LMS kurs kataloğu örneğiyle anlatır. Tam örnek prompt’lar `ornek-promptlar.md` içindedir. Katalog özelliği bu dosyalarla **uygulanmamıştır**; öğrenci için örnek görevdir.

Ana kaynak: [Claude Code Agent Teams resmî dokümanı](https://code.claude.com/docs/en/agent-teams) (erişim: 13 Ekim 2026). Proje bağlamı: `../CLAUDE.md`, `../docs/gereksinimler.md`, `../ui/DESIGN.md`.
